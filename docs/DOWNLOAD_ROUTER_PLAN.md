# 下载归档插件（downloads）设计记录

> 2026-10-24 立项调研 → 2026-10-31 架构定稿并动工。本文是产品与架构决策的落地记录，实现以代码为准。

## 定位

监视下载文件夹，按规则把新文件自动归类到指定文件夹，附搬运账本。第 8 个插件
`LesTool.Plugin.DownloadRouter`（Id：`downloads`），**宿主零改动**。

形态与空格预览同构：**自触发核心 + 一条手动命令 + 设置页**。触发×动作矩阵定案
（触发源终为 3，事件触发/后台动作不进矩阵）确认文件事件驱动的哨兵长在插件内部，
人工入口走标准注册：

- 命令 `downloads.organize`「立即整理下载」（热键/命令面板/轮盘三路可绑）
- 设置页「下载归档」（主窗口"插件"分组）
- Toast 汇总反馈

双开关分工：宿主 PluginState 总闸管"装不装载"（重启生效，插件管理页）；
插件内 `enabled` 管在岗暂停（即时生效，设置页）。

## 市场调研结论（2026-10-24）

标杆 Hazel（Mac，$42）赢在信任设计（规则预览/日志/回滚），不在功能多；Windows 上
免费+现代+持续维护的位置是空的。行业基线：监听→规则→移动+重名处理+等下载完成。
DropIt 的教训是动作膨胀（21 种动作界面复杂）。**v1 只做基线 + 账本（信任设计的最小集）**。

## v1 行为契约（安全底线，改动须慎重）

1. **半成品黑名单永不碰**：.crdownload/.part/.tmp/.download/.opdownload/.partial/.!ut/.filepart，
   黑名单先于一切免等通道生效。
2. **免排队不免安检**：免等快速道（重命名落地 = 浏览器完成标志，自动生效；白名单扩展名，
   手动配置默认空）只跳过安静等待，独占打开确认照做，被占用即降级回正常防抖。
3. **三证齐才动手**：到期 + 大小与上轮一致 + 能独占打开。
4. **无规则认领一律不动**（宁可漏搬不可错搬，不内置兜底规则，默认规则表为空）。
5. **重名永不覆盖**：自动加 " (n)" 后缀；目标夹不存在自动建。
6. **任何路径不删源文件**；失败（重试 3 次×2 秒穷尽）记失败账 + ERROR 日志，本轮放弃。
7. **每笔搬运记账**（封顶 500 条，防抖 2 秒落盘）：文件名/从/到/规则/结果/来源，可定位文件。

## 组件与线程

```
FileSystemWatcher ─ 事件(线程池，只入池无IO) ─▶ 待运池 ─ 1秒巡检(唯一搬移点,顺序) ─▶ 账本/Toast/日志
                     黑名单→免等→安静等待         大小稳+独占确认      规则匹配+安全搬
```

- 事件线程：纯名字判定 + 入池（黑名单是纯函数）。
- 巡检线程：`System.Threading.Timer`，重入保护；搬移中失败重试最长阻塞 ~6 秒（v1 取舍）。
- UI 线程：参数/规则改动 = 换不可变快照（`volatile` 引用交换），后台只读不加锁。
- 账本：后台写 UI 读，内部锁；落盘封送 UI 线程（IPluginSettings 契约）。
- 自愈：watcher Error → 重建监听 + 全量补扫（缓冲溢出/目录失联不劳用户）。
- 关停四步幂等：停监听 → 停巡检 → 等在飞收尾（上限 5 秒）→ 账本强落。

## 设置 schema（plugins/downloads/settings.json）

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 哨兵暂停键 |
| `watchFolder` | 用户下载夹 | 仅顶层，不递归 |
| `debounceSeconds` | `5` | 安静等待（1–300 夹取） |
| `fastLaneExts` | `""` | 免等白名单，逗号分隔 |
| `sweepMode` | `Prompt` | Off / Prompt（数了提示不动手，确认=手动整理）/ Auto |
| `rules` | `[]` | RouteRule{Name,Enabled,Extensions,NameContains,TargetDir}，顺序即优先级，条件 AND、留空不限 |
| `ledger` | `[]` | LedgerEntry，新在前封顶 500 |

## 规则语义

条件之间"填了才要求、填了都须满足"（AND）；扩展名/关键字都留空 = 认领一切（用户自建兜底）。
匹配只看文件名（扩展名 + 包含关键字，不区分大小写），不看内容。

## 明确不做（防膨胀清单）

日期变量子文件夹、账本一键搬回、规则试运行（v1.1 候补）；内容路由/OCR（远期，
届时复用截图模块 OCR 设施）；多监视夹、递归子目录、压缩/邮件/FTP 等动作。

## 日志点

- INFO：哨兵上岗/暂停/收摊、每笔归档（文件→目标，规则，来源）、补扫入池、启动清点、
  设置变更（开关/文件夹/防抖/白名单/档位/规则增删改排序）
- DEBUG：黑名单忽略、快速道入池、防抖续期、快速道降级、无规则认领、重试
- ERROR：归档失败（源文件原地保留）、监听异常（附自愈动作）、巡检异常、启动补扫失败、定位失败

## 工程备忘

- WPF 工程 ImplicitUsings 不含 System.IO，各文件显式 using（browser 插件踩过的坑）。
- plugin.json 含 description/icon（两本账作者账），icon = `\uE896`（MDL2 Download）。
- DeployToHost 目标沿用剪贴板插件惯例（排除 Platform/Serilog 公共 dll）。
- 账本落盘封送 UI 线程：IPluginSettings 非线程安全（无锁字典），后台直写有并发腐蚀风险。
- 定位文件走 Shell32 PIDL 原语（SHOpenFolderAndSelectItems），不走命令行拼接（Mimosa 审计红线）。

## 验收要点（用户侧）

1. 放一个 zip 进下载夹（配一条 zip 规则）→ ~6 秒内 Toast「已归档」，文件出现在目标夹，账本+1。
2. 浏览器下载中（.crdownload 存在期间）→ 不动；下载完成（改名瞬间）→ 免等快速归档。
3. 同名文件再放入 → 目标夹出现 "xxx (2)"，原文件不覆盖。
4. 无匹配文件 → 不动，日志见 DEBUG「无规则认领」。
5. 「立即整理下载」命令（可绑热键/轮盘/面板）→ 立即入池逐笔归档。
6. 关掉总开关 → 哨兵暂停（日志 INFO），命令仍可用。
