# LesTool 插件设置页 UI 规范（PLUGIN_UI_SPEC）

> 2026-10-31 立，同日二改（热键配置上页头）。用户三条公共约束的成文：①页头插件简介（可选）
> ②必有快捷键配置 ③展示图标、点击可换。本规范是插件设置页的唯一布局法源；与 DESIGN.md
> （全局设计宪法）冲突时，设置页结构以本文为准、视觉数值仍以 DESIGN.md / design-tokens.json
> 为准。机器门禁：`tools/check_ui.py` 的 sections 规则。

## 0. 主流依据（为什么这么定）

桌面设置界面的行业收敛点，四家规范殊途同归：

| 来源 | 借来的铁律 |
|---|---|
| Fluent 2 / WinUI SettingsCard | 一行一项；标签左、控件右；组有标题；页头大标题 + 区块小标题的层级 |
| VS Code / macOS 系统设置 | 行式分组；即时生效（无确定/取消）；设置项与触发绑定分区 |
| Ant Design 表单 | 标签列固定宽、全页竖向对齐；说明文字与校验错误固定在行下（不弹窗） |
| Material Design | 相关项才分组；破坏性操作隔离在最后且需确认 |

## 1. 页面骨架（A）—— 宿主独占，插件不可触碰

```
┌ ScrollViewer · PagePadding(32,24) ── 页头通栏全宽 ──────────────────────────┐
│ [图标 48×48 圆角卡片·点击换] 清单简介 Body Secondary（可选，限宽） [⌨ 未绑定/已绑 N/M] │
│ ┌ MaxWidth 860 左对齐 ─────────────────────────────────┐                   │
│ │ ▍区块标题 Body 14 SemiBold                           │                   │ ← SettingsSection
│ │   一句说明 caption 灰（可选）                         │                   │
│ │   行：标签列 120 固定 | 控件区                        │                   │ ← SettingsRow / CheckRow
│ └──────────────────────────────────────────────────────┘                   │
└────────────────────────────────────────────────────────────────────────────┘
```

- **工厂只返回"纯内容"**：`RegisterSettingsPage(Func<FrameworkElement>)` 返回一串
  `SettingsSection`（XAML 页 = 根 UserControl 下单个裸 StackPanel，子元素全是 SettingsSection，
  门禁强制；纯代码页同构）。页框（滚动/边距/行宽/页头）全部宿主管——插件想不规范都做不到。
- **三条公共约束全部宿主保证**：
  1. 简介可选——读清单 `description`，有就显示、没有不占位（作者账，只读）；名称与版本不在页头
     重复（名字左侧导航就有；版本进图标 tooltip 与插件管理页）；
  2. 快捷键必有——键位小部件固定在页头**最右**（页头通栏全宽、小部件贴内容区右缘，
     2026-11-01 拍板；页尾热键区 2026-10-31 二改退役）：**单动作**按钮直接显示键位组合、
     点击即捕获一步改；**多动作**按钮显示汇总（未绑定 / 已绑 N/M，拍板过不显示"第一个
     动作的键"——注册顺序用户不可见，必张冠李戴），点击弹下拉逐条配（内嵌紧凑版热键区，
     行型：动作名左、键位靠右，行内冲突红字不缩水）；无命令插件（如空格预览走焦点触发）
     不显示空壳；
  3. 图标可换——页头图标点击开内置字形库选择器（Segoe MDL2 精选），点选即换、即时生效。
- 多页插件：仅第一页带页头，后续页纯配置区（现状无多页插件，导航按插件名显示）。
- 捕获/校验/提交一条链路（`HotkeyOps`/`HotkeyCapture`）：热键区行与页头小部件共用，行为完全一致。

## 2. 行原语（B）—— Platform.Controls 三件套

| 控件 | 形态 | 什么时候用 |
|---|---|---|
| `SettingsSection` | 标题（Body SemiBold，与热键区同款）+ 可选一句说明 + 内容；默认上边距 32 | 区块容器，配置区只能由它堆叠 |
| `SettingsRow` | 标签列固定 120（全页竖向对齐）+ 控件区；行下可挂 `Help`（弱色）与 `Error`（危险色校验，顶替 Help 显示） | 标签+控件的表单行；**一行只放一个设置项** |
| `CheckRow` | CheckBox 句式标签（强制换行）+ 可选行下说明；`IsChecked` 可绑定，`Toggled` 事件 | 设置项本身就是一句开关语义 |

## 3. 控件用法（C）—— 一行一控件

| 需求 | 用法 | 尺寸 |
|---|---|---|
| 开关 | `CheckRow` | — |
| 数字 | TextBox + 单位 caption | 宽 64 |
| 短文本 | TextBox | 宽 200 |
| 路径/长文本 | TextBox 撑满 + 「浏览…」按钮 | 撑满 |
| ≤5 个互斥选项 | 横排 RadioButton（ComboBox 禁用，沿 DESIGN.md） | — |
| 组合键 | 只出现在页头键位小部件（含其下拉），配置区禁止键位控件 | — |

校验错误 = 行下红字（`SettingsRow.Error`），不用弹窗；禁用/半成品行（如缺目标的规则）跳过生效并在说明里写明。

## 4. 列表编辑块（D）—— 引擎表 / 规则表

- 列结构：启用勾选(32) | 定宽文本列 | 主列(*) | 行尾操作组（↑↓删，各 32+）；
- 列头 caption 可选（列义不自明时才加）；行内 TextBox 绑定 TwoWay、LostFocus 提交即存；
- 末尾「+ 添加」按钮左对齐；空列表显示一行占位 caption，不留白。

## 5. 节奏与排序（E）

- 间距走刻度：区间距 32、行距 12、行→行下说明 4；Law 5 组外距 > 组内距；
- 区序：**总开关 → 常用参数 → 规则列表 → 高级/危险**；危险动作（清空历史类）永远最后，
  做成三级 DangerBrush 文字/描边按钮 + 两击确认；
- 即时生效、即时落盘，无确定/取消按钮（沿全应用惯例）；每页至多一个主操作（PrimaryButtonStyle）。

## 6. 名实两本账（F）—— 谁管什么

| 账本 | 内容 | 谁写 |
|---|---|---|
| 作者账 `plugin.json` | 名称、版本、简介、默认图标 | 插件作者；页头只读展示 |
| 用户账 `%APPDATA%\LesTool\plugins.json` | 启用开关、**图标覆盖 `IconOverrides`** | 用户；插件升级不可覆盖 |

生效图标 = 用户账 > 作者账 > 兜底 `\uE713`；导航、插件管理页、插件页头三处统一走
`PluginState.GetEffectiveIcon` 同一解析，换图标即时生效、重启保持。

## 7. 样板

- 智能搜索 `SmartSearchSettingsPage`：三区（列表块 / CheckRow 组 / 列表块）；
- 下载归档 `RouterSettingsPage`：四区（CheckRow+主按钮 / SettingsRow 表单 / 规则列表 / 账本卡片）——表单行的标准写法看它。

## 8. 改规范怎么办

改本文 + 同步 `tools/check_ui.py`（sections 规则）+ `PLUGIN_DEV.md` §5/§8 摘要，三处互为镜像；
控件本身（Platform.Controls 三件套）的视觉参数仍走 design-tokens.json 管线，不在此调数值。
